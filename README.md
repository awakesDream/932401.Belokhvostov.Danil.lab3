Лабораторная работа №2
В этой работе произошло улучшение предыдущей лабораторной. Здесь уже используем второй файл (style.css) для перенесения туда стилей и добавления собественных переменных под цвета.
 
Было реализовано:
1. Основные цвета были перенесены в переменные, что облегчит дальнейшую разработку страницы (не придется искать цвета по #, нужно будет всего лишь указать название переменной).
2. Все важные стили в одном файле, 1 элемент c inline стилями и одно правильно в <style>.
3. Несколько типов позиционирования (static, relative, absolute).
4. НЕсколько типов состояние элементов ( :hover, :active, :focus, :visited).
5. Навигационная панель, которая во время пролистывания страницы "прилепала" к верху страницы и оставалась видимой.
6. Две колонки в посещенных странах и отступы между ними.
